# Kotlin 코딩 테스트 연습 (CodingTest_Kotlin)

이 저장소는 **Kotlin** 언어를 사용하여 백준 온라인 저지(BOJ) 및 알고리즘 문제들을 풀이한 기록입니다.
IntelliJ IDEA 환경에서 작성되었으며, 난이도별로 패키지를 나누어 관리하고 있습니다.

## 📝 프로젝트 소개

* **목표:** Kotlin 문법 숙달 및 알고리즘 문제 해결 능력 향상
* **출처:** 주로 [백준 온라인 저지(BOJ)](https://www.acmicpc.net/)의 문제들을 풀이합니다.
* **구조:** 문제의 난이도(Tier)에 따라 디렉토리를 구분하여 소스 코드를 저장합니다.

## 🛠️ 개발 환경

* **IDE:** IntelliJ IDEA
* **Language:** Kotlin (v2.2)
* **JDK:** 17
* **Library:** `kotlin-stdlib`

## 📂 디렉토리 구조 (Directory Structure)

소스 코드는 `src` 폴더 내부에 난이도별로 분류되어 있습니다.

```text
src/
├── Main.kt          # 프로젝트 메인 실행 파일 (테스트용)
├── seed/            # 입출력, 사칙연산 등 기초 문제 (새싹 난이도)
├── bronze/          # 브론즈 난이도 문제
└── silver/          # 실버 난이도 문제
